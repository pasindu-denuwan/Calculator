# 🧮 Python Calculator

A simple and user-friendly calculator application developed using **Python** and the built-in **Tkinter** GUI library.

This project was created as a beginner-friendly Python project to practice GUI development, functions, event handling, and basic programming concepts.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number calculations
- 🔲 Bracket calculations
- 🧹 Clear button
- ⌫ Backspace button
- ⚠️ Error handling
- 🖥️ Graphical User Interface (GUI)
- 🎨 Dark-themed interface

---

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter**

Tkinter is Python's standard GUI library and normally comes included with Python.
